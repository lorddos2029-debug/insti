## Executar
Abra o arquivo `index.html` no navegador. Não há necessidade de dependências, build ou servidor.

## Publicar com GitHub Pages
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Selecione **main** e a pasta **/(root)**, depois clique em **Save**.
4. Após a publicação, o endereço esperado será `https://lorddos2029-debug.github.io/insti/`.

## Personalizar
- **Conteúdo e design:** edite `index.html`.
- **Contato:** procure por `mailto:` e `tel:`.
- **Cores:** altere as variáveis CSS em `:root`.

O site não contém formulário com coleta de dados nem integrações externas de pagamento. As fontes são carregadas via Google Fonts.
